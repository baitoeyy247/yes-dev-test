# Luma Skin

ระบบหลังบ้านสำหรับแบรนด์สกินแคร์ Luma Skin ทีมงานนำเข้าสินค้าจาก Excel สร้าง QR ให้แต่ละชิ้น และลูกค้าสแกนแล้วเห็นข้อมูลล่าสุดเสมอ

## เริ่มใช้งาน

ต้องใช้ Node.js 22 ขึ้นไป

```bash
cd luma-skin
npm install
npm start
```

เปิด http://127.0.0.1:3000

บัญชี Super Admin สำหรับผู้ทดสอบ

- อีเมล `admin@lumaskin.test`
- รหัสผ่าน `Luma#Super1`

รหัสผ่านในฐานข้อมูลถูกเก็บเป็นค่าแฮช ไม่มีหน้าสมัครสมาชิก ผู้ใช้ใหม่เข้าได้จากลิงก์เชิญเท่านั้น

## ลำดับทดสอบ

1. เข้าสู่ระบบด้วย Super Admin
2. เปิดเมนูทีมงาน แล้วส่งคำเชิญให้ Admin ระบบไม่ส่งอีเมลออกจริง แต่บันทึกไว้ที่เดียวกัน เปิดลิงก์จากบันทึกนั้นเพื่อตั้งรหัสผ่าน
3. เข้าสู่ระบบด้วย Admin เมนูทีมงานจะใช้ไม่ได้
4. เปิดเมนูนำเข้า แล้วอัปโหลด `sample-data/luma_products.xlsx` ตรวจแถวที่ไม่ผ่านก่อนกดบันทึก ระบบจะเขียนเฉพาะแถวที่ถูกต้อง
5. เปิดสินค้า แล้วดู QR เปลี่ยนสีพื้นหลังกับขนาด และดาวน์โหลด PNG ได้ อัปโหลดรูปที่หน้ารายละเอียดสินค้า
6. เปิดลิงก์สาธารณะ แก้ราคาหรือรายละเอียด แล้วเปิดลิงก์เดิมซ้ำ ข้อมูลต้องเปลี่ยน และ QR เดิมยังใช้ได้
7. อัปโหลด `sample-data/luma_products_update.xlsx` เพื่ออัปเดตสินค้าเดิมและเพิ่มสินค้าใหม่ รูปกับลิงก์ QR ของสินค้าเดิมยังอยู่
8. เปิดเมนูการสแกน เพื่อดูสินค้าที่ถูกเปิดบ่อยและบันทึกเวลา IP กับ user agent

ไฟล์ตัวอย่างดาวน์โหลดได้จากหน้านำเข้าด้วย ถ้ามีไฟล์จากผู้ทดสอบเอง ใช้คอลัมน์ชุดเดียวกันได้ทันที

## สิ่งที่ไฟล์ตัวอย่างตั้งใจไว้

ไฟล์แรกมี 33 แถว ผ่าน 24 แถว ไม่ผ่าน 9 แถว เช่น รหัสว่าง ชื่อว่าง ราคาไม่ใช่ตัวเลขบวก หมวดหมู่ผิด สถานะผิด และ SKU ซ้ำในไฟล์ `LS-1504` เป็น inactive จึงไม่แสดงบนหน้าสาธารณะ สถานะว่างถูกบันทึกเป็น active

ไฟล์ที่สองมี 18 แถว จะอัปเดต 7 รายการและเพิ่ม 4 รายการ ที่ควรเห็นหลังบันทึก

- `LS-1001` เปลี่ยนชื่อเป็นสูตรใหม่ ราคา 940 และ QR เดิมยังเปิดหน้านี้
- `ls-1002` อัปเดตสินค้า `LS-1002` แม้ตัวพิมพ์จะต่างกัน ราคาเป็น 820
- `LS-1204` กลายเป็น inactive และหน้าสาธารณะไม่แสดงชื่อสินค้า
- `LS-1203` มีแถวราคาติดลบ จึงไม่ทับข้อมูลเดิม
- `LS-1601`, `LS-1208`, `LS-1006`, `LS-1306` เป็นสินค้าใหม่
- รูปที่อัปโหลดไว้ไม่หาย เพราะไฟล์ Excel ไม่มีรูป

ถ้า SKU เดียวกันซ้ำในไฟล์มากกว่าหนึ่งแถว ระบบไม่บันทึกแถวที่ซ้ำเลย

## บทบาท

- Super Admin ทำได้ทุกอย่าง และเป็นคนเดียวที่เชิญผู้ใช้ใหม่ได้
- Admin นำเข้าสินค้า แก้ข้อมูล อัปโหลดรูป ปรับ QR และดูสถิติการสแกน

## รูปสินค้า

อัปโหลดที่หน้าแก้ไขสินค้า รับ JPG, PNG หรือ WEBP ขนาดไม่เกิน 2 MB ระบบตรวจจากเนื้อไฟล์ ไม่ใช่แค่นามสกุล สัดส่วนที่แนะนำคือสี่เหลี่ยมประมาณ 800×800 px แต่ไม่ได้บังคับ ไฟล์ที่ไม่เข้าเงื่อนไขจะถูกปฏิเสธพร้อมบอกเหตุผล

## ทดสอบบนมือถือ

QR ที่ดาวน์โหลดจะฝังที่อยู่ของเซิร์ฟเวอร์ตอนที่กดดาวน์โหลด ถ้าจะให้โทรศัพท์ในวงเดียวกันเปิดได้ ให้รันด้วยที่อยู่ของเครื่อง

```bash
APP_BASE_URL=http://192.168.1.20:3000 npm start
```

จากนั้นดาวน์โหลด QR ใหม่ ข้อมูลสินค้าที่แก้ทีหลังยังแสดงผ่าน QR เดิม

ตัวแปรอื่น: `PORT`, `HOST`, `SUPER_ADMIN_EMAIL`, `SUPER_ADMIN_PASSWORD`, `SUPER_ADMIN_NAME`
